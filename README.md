# Md. Kamrul Islam — Professional Portfolio

A personal portfolio website for **MD. KAMRUL ISLAM** — *Assistant Officer (ERP & MIS), IT & Data Analysis Professional*.

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4**. Fully responsive, accessible, SEO-optimized, and configured for **Vercel** and **GitHub**.

---

## ✨ Features

- **Theme & Accent Customization**:
  - Default Light Mode (clean white canvas) + Alternate Dark Navy Mode
  - 5 Selectable Accent Palettes: Electric Blue, Vibrant Cyan, Royal Purple, Emerald Green, Rose Pink
  - Persistent state saved to `localStorage` with zero-flicker transitions
- **Comprehensive Sections (Strictly from CV)**:
  - **Sticky Navbar**: With "Available for Opportunities" pulsating badge, quick navigation, mobile drawer, and theme selector.
  - **Hero Section**: Executive introduction, verified career title, quick action CTAs, and portrait card with floating ERP & MIS badge.
  - **About Me**: CV career objective, summary, language proficiencies, and 4 professional qualities.
  - **Work Experience ("My Work Journey")**: Vertical timeline detailing positions at Jann Composite Mills Ltd, Alpona Graphics Design, and Labbib Computer Training Center.
  - **Technical Skills**: Categorized into ERP & MIS, Microsoft Office, Programming, Networking, and Design & Multimedia.
  - **Featured Projects**: Interactive cards with live demo links, source code, and project preview modal.
  - **All Tech Academy BD**: Dedicated promotional banner with verified links to the blog and YouTube channel.
  - **Education**: Academic degree credentials (Khwaja Yunus Ali University, HSC, SSC) and extracurricular volunteering.
  - **FAQ Accordion**: 8 answers covering ERP, MIS workflows, technical skills, and collaborations.
  - **Contact & Direct Reach**: Phone, Email, WhatsApp, LinkedIn, GitHub, YouTube, and an interactive message dispatcher.
  - **Premium Footer**: Dark navy footer with quick links, copyright, and smooth back-to-top button.

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
The compiled static assets will be in the `dist/` directory.

---

## 🌐 Deploy to Vercel

1. Push this repository to **GitHub**.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite**.
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **Deploy**.
